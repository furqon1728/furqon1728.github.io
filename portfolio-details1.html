Community Website

This project is a web-based alumni information system designed for the “Tenacious” generation of La Tansa Boarding School, created as part of my academic research. The design utilizes UML modeling and Figma prototyping to build a clear and structured interface that supports communication among alumni, news sharing, and job posting announcements. The result is a prototype that demonstrates how complex requirements can be translated into an intuitive and engaging user experience.
